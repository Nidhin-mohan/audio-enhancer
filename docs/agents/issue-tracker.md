# Issue tracker: GitHub

Issues for this repo live in GitHub Issues on `Nidhin-mohan/audio-enhancer`.

- Create: `gh issue create --repo Nidhin-mohan/audio-enhancer --title "..." --body-file <file> --label <label>`
- Read: `gh issue view <number> --repo Nidhin-mohan/audio-enhancer --comments`
- List: `gh issue list --repo Nidhin-mohan/audio-enhancer --label <label>`
- Comment: `gh issue comment <number> --repo Nidhin-mohan/audio-enhancer --body-file <file>`
- Labels that don't exist yet are created on first use (`gh label create`).
- `gh` is authenticated as Nidhin-mohan (the personal account). Never act on this repo as Nidhin-phs.
