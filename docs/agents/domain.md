# Domain docs

Layout: single-context.

- `CONTEXT.md` (repo root) is the domain glossary. Use its terms exactly in code, UI labels, issues and specs (Recording, Stem, Separation, Noise Reduction, Vocal Boost, Pitch Correction, Key, Pitch Correction Preset, Trim, Mix, Mixdown). Honour each term's "Avoid" list.
- `docs/adr/` holds architecture decisions. Read the ADRs touching your area before changing it, and don't contradict one without writing a superseding ADR.
- If you find a term missing or used inconsistently, flag it rather than inventing a new word.
